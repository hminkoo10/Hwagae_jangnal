# 과거 이력으로 고른 세 가지 판매 사례

상품명·품목 종류는 원본에 없으므로 Walmart 매장·상품 번호로만 설명합니다. 판매량 단위는 개이며 소수 예측값은 반올림하지 않았습니다. 일별 P50의 합은 비교를 위한 합산값이며 주간 합계 수요 분포의 중앙값을 뜻하지 않습니다.

세 상품은 미래 실제값이나 모델 예측을 읽기 전에 56일 이력만으로 골랐습니다. 56일 모두 양수인 5상품 중 CV(모표준편차/평균)의 중앙값을 일반 판매, CV 최대를 변동 판매로 선택합니다. 전체 10상품 중 0판매일이 가장 많은 상품을 0판매 사례로 고릅니다. 동률은 매장·상품 번호 숫자 오름차순입니다. ‘일반’은 이 작은 후보 집합의 상대적 명칭이며 전체 상품 대표성을 뜻하지 않습니다.

세 사례의 요일 기준선은 현재 API의 실제 함수를 **동일한 56일 입력**에 적용했습니다. 전체 평가의 API 기준선은 84일 입력이며 개선율 6.98%/10.71%는 그 집계 결과입니다. 아래 세 사례의 수치로 그 개선율을 계산하거나 일반화하지 않습니다. P10~P90은 명목 80% 예측 구간이며 7일의 관측 포함률은 보정의 증거가 아닙니다.

## 일반 판매 — Walmart 매장 24, 상품 43

기준일 2014-09-12, 예측 기간 2014-09-13~2014-09-19. 과거 56일 평균 38.393, 모표준편차 14.071, CV 0.3665, 0판매 0/56일, 범위 2~71개입니다.

7일 실제 합계 151개, TFT P50 합계 209.497개. TFT MAE **8.821**, API 요일 기준선 MAE **15.714**. 구간 포함률은 각각 57.1%, 42.9%입니다.

이 7일에는 실제 0판매일이 없어 0판매일 오차는 null입니다.

이 수치는 선택한 단일 상품·단일 7일 구간의 결과입니다. 날씨 사용 여부의 인과 효과나 한국 매장의 정확도를 보여주지 않습니다.

## 재현

저장소 루트에서 `python -m ml.analyze_cases --no-plots`로 JSON·CSV·설명을 재생성합니다. 모델 실행·재학습은 없습니다. 차트까지 생성하려면 별도 문서용 환경에 `matplotlib==3.11.2`를 설치하고 `--no-plots`를 빼세요. 기존 고정 추론 환경을 변경할 필요가 없습니다. `--output-dir`로 다른 폴더에 저장할 수 있습니다.

입력·현재 API 기준선 함수·분석 코드 해시는 `cases.json`과 `failure-cases.json`에 기록합니다. 원본 평가 ZIP/멤버 해시를 확인하며, 미래 actuals는 추론 입력 파일에 합치지 않습니다. 수치 비교는 JSON/CSV를 기준으로 하고 그림은 설명용입니다.
