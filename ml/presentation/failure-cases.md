# 원본 테스트의 큰 실패 사례

상품명·품목 종류는 원본에 없으므로 Walmart 매장·상품 번호로만 설명합니다. 판매량 단위는 개이며 소수 예측값은 반올림하지 않았습니다. 일별 P50의 합은 비교를 위한 합산값이며 주간 합계 수요 분포의 중앙값을 뜻하지 않습니다.

이 사례는 원본 테스트에서 최근 56일이 모두 관측된 243개 window를 7일 P50 MAE 내림차순으로 정렬한 뒤 서로 다른 매장·상품쌍 세 개를 골랐습니다. **미래 오차를 본 사후 실패 선택**입니다. 성능의 대표 표본이나 새로운 평가 집합이 아닙니다. 저장된 GPU 예측을 사용하며 CPU 샘플과 혼용하지 않습니다. API 기준선은 해당 기준일까지 최대 84일 관측만 받습니다.

## 실패 1 — Walmart 매장 17, 상품 9

기준일 2014-09-12, 예측 기간 2014-09-13~2014-09-19. 과거 56일 평균 90.839, 모표준편차 32.130, CV 0.3537, 0판매 0/56일, 범위 24~163개입니다.

7일 실제 합계 1009개, TFT P50 합계 495.522개. TFT MAE **73.354**, API 요일 기준선 MAE **52.071**. 구간 포함률은 각각 28.6%, 42.9%입니다.

이 7일에는 실제 0판매일이 없어 0판매일 오차는 null입니다.

- **관측 사실:** strict56 window MAE 순위 1위. 과거 56일 평균 90.839개 → 직전 7일 평균 107.286개(+18.1%) → 다음 7일 실제 평균 144.143개(직전 주 대비 +34.4%)입니다. 실제 6/7일이 과거 평균보다 높고 2/7일이 과거 최댓값을 넘었습니다.
- **최대 오차일:** 2014-09-15의 actual 235, P50 66.386, P90 117.456, 절대 P50 오차 168.614개입니다. 이날 실제값은 과거 56일 범위 24~163개 벗어났습니다. 전체 주간 실제값이 P90을 넘은 날은 5일, P10보다 낮은 날은 0일입니다.
- **원인 추정:** 직전 7일 평균에 이미 상승이 나타났고 다음 주에는 과거 범위 밖의 고점도 생겼습니다. 모델 출력이 최근 수준 상승과 추가 고점을 충분히 따라가지 못한 가능성을 검토합니다. 이는 출력 패턴 해석이며 내부 원인이나 특정 외부 요인을 입증하지 않습니다. 판매 관측만으로 잠재 수요와 공급 제약을 구분할 수 없으며 프로모션·품절·날씨 효과는 단정하지 않습니다.
- **확인할 자료:** 해당 날짜의 재고·품절 기록, 판매 가격·프로모션, 영업 여부·휴점, 상품 변경 및 행사 기록, 예보 발급 시각이 있는 날씨 자료가 필요합니다.
- **개선 방향:** 검증 구간에서 최근 7일 수준과 56일 수준의 비율별 오차를 나누고 최근 수준을 따라가는 단순 기준선도 비교합니다. 상승 구간의 상단 분위수 보정은 검증 자료에서 설계하고 새 미래 홀드아웃에서 확인합니다. 이 실패 테스트 행에 맞춰 조정한 결과를 기존 테스트 개선으로 재보고하지 않습니다.

## 실패 2 — Walmart 매장 4, 상품 9

- **개선 방향:** 최대 오차일의 요일별 과거 관측과 D+7 예측 편향을 우선 확인하고, 최근 수준·요일별 기준선에 비해 낮아지는 구간을 검증 집합에서 분리합니다. 날짜 정렬과 해당일 원자료도 검토한 뒤 보정을 별도 미래 홀드아웃으로 평가합니다. 이 실패 테스트 행에 맞춰 조정한 결과를 기존 테스트 개선으로 재보고하지 않습니다.

## 재현

저장소 루트에서 `python -m ml.analyze_cases --no-plots`로 JSON·CSV·설명을 재생성합니다. 모델 실행·재학습은 없습니다. 차트까지 생성하려면 별도 문서용 환경에 `matplotlib==3.11.2`를 설치하고 `--no-plots`를 빼세요. 기존 고정 추론 환경을 변경할 필요가 없습니다. `--output-dir`로 다른 폴더에 저장할 수 있습니다.

입력·현재 API 기준선 함수·분석 코드 해시는 `cases.json`과 `failure-cases.json`에 기록합니다. 원본 평가 ZIP/멤버 해시를 확인하며, 미래 actuals는 추론 입력 파일에 합치지 않습니다. 수치 비교는 JSON/CSV를 기준으로 하고 그림은 설명용입니다.
