# 모델 작업 공간

Colab 담당자의 데이터 전처리·학습·평가·추론 코드 작업 영역입니다.
이번 세팅에는 모델, 학습 데이터, GPU 라이브러리를 설치하거나 포함하지 않았습니다.
API 개발용 가상환경과 Colab 학습 환경은 분리합니다.

## 다음 작업에서 추가할 파일

- `train.py`: 학습 코드
- `predict.py`: API 서버에서도 실행 가능한 추론 코드
- `requirements.txt`: 실제 Colab 환경에서 검증한 학습 라이브러리 버전
- 작은 샘플 입력·출력과 모델 평가 결과

## API 담당자와 먼저 합의할 것

- 판매 기록의 열 이름과 단위: `date`, `product_id`, `units_sold`
- 날씨 예보의 발표 시각과 예측 대상 날짜
- 학습·추론 시 사용하는 특성, 전처리, 분위수 목록
- 모델 파일·전처리 파일·라이브러리 버전의 전달 방법

큰 원본 데이터와 학습 모델은 Git에 올리지 않습니다.
로컬 데이터는 루트 `data/raw/`, 가공 데이터는 `data/processed/`,
모델 파일은 `artifacts/`에 두면 기본 `.gitignore`에서 제외됩니다.

Colab 노트북을 추가할 때는 토큰·개인정보·대용량 출력을 지우고 커밋하세요.
