# 서비스 운영자 · 점주 가입 흐름

서비스 운영자는 점주·직원과 별도 권한입니다. 운영자로 로그인하면 계약·계정·매장 현황 화면이 열립니다. 운영자는 점주의 AI 키·판매 상세에 자동 접근하지 않습니다. 기존 점주·직원 계정과 판매·재고·발주 자료는 그대로 유지됩니다.

## 사용 순서

1. 운영자 로그인 → **계약 등록 · 점주 초대**. 점주 이름·로그인 이메일·계약 시작일·종료일을 입력합니다.
2. 새 계정이면 생성된 초대 링크를 복사해 점주에게 전달합니다. 앱에서 자동으로 이메일을 발송하지는 않습니다. 링크는 7일 유효하고 한 번만 사용할 수 있습니다. 재발급하면 이전 미사용 링크는 폐기됩니다.
3. 점주는 링크를 열고 12자 이상 비밀번호를 직접 설정합니다. 서버에는 비밀번호 해시만 저장하며 운영자는 비밀번호를 볼 수 없습니다. 초대 토큰은 DB에 해시로만 저장하고, 브라우저 주소의 fragment에서 읽은 뒤 지웁니다. API로는 본문에 전송합니다.
4. 점주 로그인 → **매장 추가** → 주소·매장명과 지역 검색 → 후보 선택. 좌표와 시간대를 자동 입력합니다. 지도에서 실제 매장 위치를 확인한 뒤 저장합니다. 상품·판매·재고 자료 업로드 후 예측·발주를 사용합니다.
5. **계약·계정 관리**에서 계약 기간, 계약 유지/이용 중지, 계정 사용 허용을 변경합니다. 계약 날짜는 한국 날짜 기준이고 시작·종료일을 모두 포함합니다. 계약 시작 전·만료·중지·계정 비활성 상태에서는 점주 로그인이 차단됩니다. 기존 세션도 다음 인증부터 거부하며 중지 시 점주의 세션을 삭제합니다. 해당 점주 매장의 직원 접근도 차단합니다.
6. 기존 점주는 **기존 점주 계정 → 계약 연결**로 연결합니다. 같은 이메일의 기존 계정은 새 비밀번호나 초대를 만들지 않고 기존 계정에 계약을 연결합니다. 계약을 아직 연결하지 않은 기존 계정은 종전대로 사용할 수 있습니다. 계약 등록·변경·초대 재발급·가입은 감사 기록에 남깁니다.

운영 현황은 실제 DB에서 집계한 점주 상태, 전체 매장·발주 계획 수, 점주별 매장·상품 수와 마지막 판매 기록 날짜입니다. 실제 결제·전자 서명 시스템이 아닌 운영자가 입력한 계약과 이용 상태를 관리합니다.

## 운영자 최초 생성

공개 가입 API로 운영자가 될 수 없습니다. 서버에서 명시적으로 실행합니다. API와 같은 `DB_PATH` 환경을 사용하며 이미 존재하는 일반 계정은 이 명령으로 승격하지 않습니다. 기존 운영자에게 다시 실행해도 비밀번호를 바꾸지 않습니다.

```sh
PYTHONPATH=apps/api .venv/bin/python -m app.bootstrap_owner \
  --email 'hwagae@milky.kr' \
  --credentials-output '/srv/hwagae/shared/platform-owner-initial.txt'
```

초기 비밀번호는 새 파일에만 기록합니다. 파일을 기존 파일 위에 쓰지 않으며 Linux 권한은 `0600`입니다. 키나 비밀번호를 로그·Git·PR에 붙이지 마세요. 사용자에게 안전하게 전달한 후 서버의 초기 전달 파일은 제거합니다. 기존 서비스 환경 파일을 출력하지 마세요.

## 위치 검색과 화면

[Photon 공식 API](https://photon.komoot.io/)의 공개 장소 검색을 사용합니다. 명시적인 검색 버튼으로만 호출하고 검색/시간대 결과를 7일 캐시하며 요청 종류별 최소 1초 간격을 적용합니다. 공개 서비스는 과도한 사용을 제한하고 가용성을 보장하지 않으므로 대규모 운영에서는 자체 Photon 또는 적절한 유료 제공자를 사용해야 합니다. 검색 출처와 [OpenStreetMap 기여자](https://www.openstreetmap.org/copyright)를 화면에 표시합니다. [Open-Meteo](https://open-meteo.com/en/docs)의 `timezone=auto`로 선택 좌표의 시간대를 확인합니다. 도시·지역 중심점이 나올 수 있으며 건물 위치 정확도를 보장하지 않습니다. 검색 실패 시 좌표·시간대 직접 입력을 지원합니다.

웹과 앱은 공통 날짜·선택 창을 사용합니다. 폼에는 날짜를 ISO 형식으로 전달하고 기존 API를 유지합니다. 작은 화면은 표를 항목 이름이 있는 카드로 표시하고 메뉴를 줄바꿈합니다. 차트는 화면 너비에 맞춥니다. 포인터 선택의 기본 파란 외곽선은 없애고 키보드 탐색에는 초록색 초점을 유지합니다. 본문·긴 목록·작은 화면의 대화상자에는 필요한 세로 스크롤을 허용합니다.

자동 검사 범위: 권한 분리, 초대 만료·재발급·동시 중복 사용, 첫 매장 생성, 계약 만료·중지 시 접근 차단, 데이터 보존, 주소 캐시·좌표 순서·시간대, 실제 렌더링 컴포넌트의 폼 값·날짜 표시·표 레이블. Work의 로컬 브라우저 사용이 비활성화되어 화면 직접 검수와 실제 Android·iPhone 설치 검증은 별도로 필요합니다.
