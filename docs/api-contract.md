# API 연결 규약

현재 구현된 API는 개발 환경 확인을 위한 `GET /health`뿐입니다.
발주·판매 기록·예측 API는 이후 두 담당자가 합의한 뒤 구현합니다.

## 현재 구현: GET /health

- 로컬 주소: `http://127.0.0.1:8000/health`
- 성공 응답: HTTP 200
- 목적: API 프로세스의 응답 여부 확인. DB나 모델 상태는 포함하지 않음.

```json
{
  "status": "ok",
  "service": "hwagae-jangnal-api",
  "version": "0.1.0"
}
```

- 대화형 문서: `http://127.0.0.1:8000/docs`
- OpenAPI 스키마: `http://127.0.0.1:8000/openapi.json`

## 기능 구현 전에 합의할 항목

1. CSV의 필수 열, 날짜 형식, 판매 수량의 단위
2. 요청·응답 JSON과 오류 형식
3. 모델 입력의 특성·시간 범위와 출력 분위수
4. 원가·판매가·가용 재고·입고 예정 수량의 의미
5. 실제 예측·시뮬레이션·데모 결과를 구분하는 방법

새 HTTP 메서드를 추가할 때 `apps/api/app/main.py`의 CORS 허용 메서드도
해당 API에 맞게 갱신합니다. 기본 세팅은 `GET`만 허용합니다.
