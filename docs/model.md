# 예측 모델

화개장날은 PyTorch Forecasting의 Temporal Fusion Transformer(TFT)로 상품별 다음 7일 판매를 예측합니다. 두 모델이 있습니다.

| 모델 | 위치 | 쓰는 곳 |
| --- | --- | --- |
| 일반 매장용 TFT | `ml/merchant_tft/` (체크포인트 포함) | 모든 일반 매장의 예측과 발주 |
| Walmart TFT | `ml/` (체크포인트는 서버에만 보관) | Walmart 자료로 만든 체험 매장과 모델 체험 화면 |

두 모델 모두 API와 분리된 Python 3.11 프로세스(`ops/tft_worker.py`)에서 CPU로 추론합니다. 요청 중에 학습하거나 모델을 내려받지 않습니다.

## 입력과 출력

API는 매장의 상품, 기준일까지의 판매 기록, 다음 7일 날씨를 모델에 넘깁니다.

- 상품마다 기준일을 포함한 최근 **연속 56일** 판매가 필요합니다. 기록이 없는 날을 0으로 채우지 않으며, 하루라도 빠지면 그 상품은 `insufficient_history`로 예측하지 않습니다. 실제로 기록된 0은 유효한 값입니다.
- 날씨는 기준일 다음 날부터 7일의 최고·최저 기온(°C)과 강수량(mm)입니다. 오늘 기준이면 실제 예보, 과거 날짜면 과거 재분석을 씁니다(Open-Meteo).
- 출력은 상품별·날짜별 판매 개수의 P10·P50·P90입니다. 학습은 0.1·0.25·0.5·0.75·0.9 다섯 분위수로 하고, API에는 세 개만 전달합니다.
- 기준일 이후의 실제 판매는 모델 입력에 넣지 않고, 화면에서 비교용으로만 붙입니다.

## 일반 매장용 TFT

디미고사회적협동조합 매점의 실제 POS 판매 중 앞 70% 기간(2025-10-01~2026-07-11, 판매일 223일)과 안산 와동의 과거 재분석 날씨로 학습했습니다. 뒤 30% 기간(2026-07-12~2026-10-24)은 학습과 설정 선택에 쓰지 않았습니다.

- **encoder 입력**: 판매(56일 평균으로 나눔), 요일, 기준일과의 거리
- **decoder 입력**: 요일, 기준일과의 거리, 같은 7일 예보 평균 대비 최고·최저 기온 차이, 강수량
- 매장·상품 ID, 상품 종류, 가격, 학사일정은 입력하지 않습니다. 처음 보는 매장과 상품도 같은 방식으로 예측합니다.
- 기온은 주간 평균 대비 차이로 넣습니다. 자료가 한 학년도뿐이라 절대 기온이 계절과 방학을 대신 나타냈기 때문입니다.
- 학습 날씨에는 예보 오차를 흉내 낸 잡음을 더했습니다. 실제로 발급된 예보로 학습한 것은 아닙니다.

### 검증

70% 기간 안에서 시간순으로 나눠, 마지막 6주(2026-05-30~07-11, 65,912 상품·일)로 검증했습니다. 같은 행에서 API의 요일 기준선과 비교했습니다.

| 모델 | MAE(개) | P10/P50/P90 pinball | P10~P90 포함률 |
| --- | ---: | ---: | ---: |
| **TFT** | **1.195** | **0.386** | 0.894 |
| 요일 기준선 (56일) | 1.285 | 0.427 | 0.802 |
| 요일 기준선 (최대 84일) | 1.265 | 0.417 | 0.807 |
| TFT, 날씨 제거 | 1.180 | 0.381 | 0.872 |

- TFT의 MAE는 요일 기준선보다 7.0%(56일), 5.5%(84일) 낮습니다.
- 이 검증 기간에서는 날씨를 뺀 모델이 조금 더 좋았습니다. 이 자료만으로 날씨가 정확도를 높인다고 말할 수는 없습니다.
- seed 한 번의 결과이며, 다른 매장의 정확도는 검증하지 않았습니다.

### 재현

체크포인트는 tensor `state_dict`만 담고 있으며, 추론 전에 `manifest.json`의 SHA-256과 구조를 확인한 뒤 `torch.load(weights_only=True)`로 읽습니다.

```bash
.model-venv/bin/python -m unittest discover -s ml/tests -p test_merchant_tft.py
.model-venv/bin/python -m ml.merchant_tft.train --data-dir <학습 자료 폴더> --output-dir <빈 폴더>
```

학습 자료는 비공개라 저장소에 없습니다. `manifest.json`에 입력 파일 해시와 학습 설정, 8개 설정의 비교 결과가 있습니다.

## Walmart TFT

Kaggle "Walmart Recruiting II: Sales in Stormy Weather"의 판매·날씨 자료로 학습했습니다. 같은 56일 → 7일 구조이며, 학습된 범주 인코더와 정규화를 체크포인트에서 그대로 복원합니다.

- 시험 구간에서 API 요일 기준선 대비 MAE가 6.98%(전체 1,139개 예측 창), 10.71%(최근 56일이 모두 관측된 243개 창) 낮았습니다. 평가표는 `ml/evaluation/`에 있습니다.
- 체크포인트(`best-epoch=02-val_loss=3.9847.ckpt`)는 저장소에 넣지 않고 서버의 `shared/models/`에 둡니다. 없으면 Walmart 관련 기능만 꺼집니다.

## 시연 자료 만들기

`scripts/make-dimigo-data.py`는 디미고 매점 POS 원본(Excel)에서 학습용 70% 자료, 평가용 30% 자료, 새 매장에 올릴 시연 파일을 만듭니다. 시연 파일은 요일을 맞추려고 날짜를 7일 단위로 옮기며, 재고 기준일이 업로드하는 날이어야 하므로 시연 날짜마다 다시 만듭니다.

```bash
uv run python scripts/make-dimigo-data.py --orders <구매 xlsx> --sales <판매 xlsx> --output <폴더> --demo-date <시연일>
```
