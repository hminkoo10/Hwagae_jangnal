# 운영 안내

## 역할과 화면

| 화면 | 대상 | 하는 일 |
| --- | --- | --- |
| `/admin` (웹), '화개장날 관리자' 앱 | 서비스 운영자 | 점주 계약·초대, 계정 관리, 공통 AI 연결 |
| `/` (웹), '화개장날' 앱 | 점주·직원 | 매장 운영: 예측, 판매·재고 입력, 발주 |

운영자가 `/`나 '화개장날' 앱으로 로그인하면 관리자 페이지나 '화개장날 관리자' 앱을 안내하고, 점주·직원이 `/admin`이나 '화개장날 관리자' 앱으로 로그인하면 매장 화면이나 '화개장날' 앱을 안내합니다. '화개장날' 앱에는 관리자 화면이, '화개장날 관리자' 앱에는 매장 화면이 들어가지 않습니다.

## 서비스 운영자

1. **계약 등록 · 점주 초대**: 점주 이름, 로그인 이메일, 계약 시작일·종료일을 입력하면 초대 링크가 만들어집니다. 링크를 복사해 점주에게 전달합니다(이메일 자동 발송 없음).
2. 초대 링크는 7일 동안 한 번만 쓸 수 있고, 다시 발급하면 이전 링크는 폐기됩니다. 이미 가입한 이메일은 기존 계정에 계약을 연결합니다.
3. **계약·계정 관리**에서 기간, 이용 중지, 계정 사용 여부를 바꿉니다. 계약 기간이 아니거나 중지된 점주와 그 매장의 직원은 로그인할 수 없습니다.
4. **AI 연결**: 모든 매장이 함께 쓰는 AI 게이트웨이를 설정합니다. OpenAI 호환, OpenAI Responses, Claude(Anthropic) 형식을 지원하고, 연결을 여러 개 저장하면 실패할 때 다음 연결로 넘어갑니다. AI가 연결되지 않으면 매장 화면은 안내 화면만 보여줍니다.

AI 키는 서버에서 Fernet으로 암호화해 저장하고, 화면이나 응답으로 돌려주지 않습니다. 암호화 키 파일(`ai-master.key`)은 DB와 함께 백업해야 합니다. 게이트웨이는 공개 HTTPS 주소만 허용합니다.

## 점주

1. 초대 링크에서 12자 이상 비밀번호를 정하고 로그인합니다.
2. **매장 추가**: 매장 이름을 넣고 지역을 검색해 위치를 고릅니다. 이 위치의 날씨로 예측합니다.
3. **초기 자료 가져오기**: 상품·판매·재고 Excel을 올리고, 내용을 확인한 뒤 저장합니다. 상품이 없는 새 매장에서만 할 수 있습니다.
4. 홈의 안내 순서대로 **7일 판매 예측 → 재고 확인 → 발주 계획**을 진행합니다. 발주량을 계산해 수량을 고치고 저장한 뒤, 확정하고 CSV·Excel로 내보냅니다.
5. 이후 판매는 **판매 기록**에서 파일이나 직접 입력으로 추가합니다. 예측은 기준일 당일 판매까지 필요하므로, 오늘 판매가 없으면 예측 화면의 **마지막 판매일로** 버튼으로 볼 수 있습니다.

### 초기 자료 양식

| 시트 | 첫 행 |
| --- | --- |
| `상품` | id, name, category, supplier, price, cost, lead_days, shelf_days, review_days |
| `판매` | date, product_id, units_sold |
| `재고` | product_id, measured_on, quantity, expires_on, arrives_on |

- 날짜는 YYYY-MM-DD, 수량과 가격은 정수입니다.
- 재고는 모든 상품을 매장 현지 **오늘** 기준으로 적습니다. 실제 0개도 0으로 적습니다. `arrives_on`을 채우면 입고 예정(내일부터)입니다.
- 매장당 상품 1~50개, 시트당 10,000행, 파일 5MB까지입니다. 수식은 받지 않습니다.

## 직원 관리

점주는 **직원 관리**에서 이름과 이메일, 할 수 있는 일을 정해 직원을 초대합니다. 새 이메일이면 7일짜리 1회용 링크가 만들어지고, 이미 가입한 계정이면 비밀번호를 바꾸지 않고 바로 직원으로 추가됩니다.

| 권한 | 기본값 |
| --- | --- |
| 판매 기록 입력 | 켬 |
| 재고 확인 입력 | 켬 |
| 발주 계획 저장 | 켬 |
| 발주 확정·내보내기 | 끔 |
| 상품 관리(추가·수정·제외) | 끔 |

- 권한은 서버에서 검사하고, 화면에서는 권한이 없는 버튼을 숨기거나 막습니다.
- 매장 추가, 초기 자료, 예측 설정, AI 도우미, 직원 관리는 점주만 할 수 있습니다.
- **사용 중지**하면 그 매장에 들어올 수 없고, 다른 소속이 없으면 로그인도 끊깁니다. **매장에서 제외**하면 소속만 지우고 계정과 작성한 발주는 남깁니다.
- 초대, 권한 변경, 중지, 제외는 감사 기록에 남습니다.
