# AI 연결 설정 (서비스 운영자)

서비스 운영자 화면의 **AI 연결**에서 한 번 설정하면 모든 매장의 매장 도우미·발주 이유·메모 정리가 같은 연결을 사용합니다. 점주와 직원은 설정·키·모델 목록·연결 테스트에 접근할 수 없고, 매장에서는 연결 준비 여부만 확인합니다. AI가 연결되지 않으면 매장 화면은 안내 화면으로 막힙니다. API: `GET/PUT /platform/ai/settings`, `POST /platform/ai/models`, `POST /platform/ai/test` (운영자 전용), `GET /stores/{id}/ai/status`. 예전 매장별 설정(`ai_settings`)은 읽지 않으며 운영자가 키를 새로 입력합니다.

1. **도우미 연결하기** → **받은 연결 정보를 입력해요**에서 이름·서비스 주소·연결 키(API 키)를 입력합니다. 기본 주소 예: `https://gateway.example/v1`.
2. **연결할 서비스**에서 **OpenAI 호환 서비스**, **OpenAI Responses 서비스**, **Claude (Anthropic)** 중 하나를 선택합니다. Claude 공식 주소 `https://api.anthropic.com`은 자동 인식하고 `/v1`을 붙입니다. `/v1/messages` 같은 개별 요청 경로는 입력하지 않습니다. Gemini 등의 다른 자체 형식은 OpenAI 호환 형식으로 변환하는 게이트웨이가 필요합니다.
3. **사용할 AI 찾기**로 `/models`에서 받은 ID를 선택합니다. 목록 미지원 공급사는 **AI 이름 직접 입력**을 선택합니다. 목록 조회만으로 설정을 저장하지 않습니다.
4. 추론 강도를 선택합니다. **모델 기본값**은 강도 파라미터를 생략합니다. `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`의 지원 여부는 모델마다 다릅니다. 지원하지 않는 값을 공급사가 거부하면 설정을 임의로 바꾸지 않고 다음 연결로 전환합니다.
5. 연결을 저장하고 **사용**을 켭니다. **위로·아래로**로 순서를 바꿉니다. 사용을 끈 연결은 건너뜁니다. 최대 8개를 저장합니다.
6. **AI 응답 확인**으로 실제 요청을 확인합니다. 어떤 연결이 성공했는지, 이전 연결의 실패 종류를 표시합니다. 추론 강도는 **고급 설정**에서 바꿀 수 있고, 안내받은 값이 없으면 **모델 기본값**을 유지합니다.

연결 한 번은 최대 약 25초, 전체 호출은 약 70초까지 기다립니다. 인증 실패·호출 제한·시간 초과·공급사 오류·빈 응답·미완료 응답이면 다음 사용 중인 연결로 넘어갑니다. 공급사 리다이렉트는 따르지 않습니다. 실패한 연결을 영구 비활성화하지 않으며 새 요청은 다시 1순위부터 시작합니다. 시간 초과된 요청도 공급사에서 처리·과금할 수 있습니다. 출력·추론 토큰 한도는 요청당 8,192입니다.

발주량 계산 후 자동으로 보여주는 **발주 이유**에도 같은 선택·우선순위·전환 규칙을 적용합니다. 계산 당시 상품·재고·입고와 날짜별 날씨·예상 판매 합계가 활성화한 게이트웨이에 전달됩니다. AI는 수정 전 추천의 이유만 설명하며 TFT 예측이나 추천·최종 발주 수량을 변경하지 않습니다. 매장 자료가 바뀌면 발주를 다시 계산합니다.

## 키 보관과 운영

- Nginx의 API `proxy_read_timeout`은 **80초**로 설정합니다. 저장소의 두 설정 예제에 반영되어 있으며 기존 운영 서버에는 별도 적용이 필요합니다. 30초 설정은 1순위 시간 초과 후 전환을 기다리는 요청을 먼저 끊을 수 있습니다.
- API 키는 서버에서 Fernet으로 암호화합니다. 조회·저장 응답과 모델 목록에는 원문 키나 암호문을 돌려주지 않습니다. 브라우저 저장소에 키를 저장하지 않습니다. 입력값 검증 오류도 원문 요청을 노출하지 않습니다.
- 키를 비워 수정하면 기존 키를 유지합니다. 게이트웨이 주소가 바뀌면 새 키 입력이 필수입니다. 다른 주소로 기존 키를 자동 전송하지 않습니다.
- 기본 암호화 키 파일은 `DB_PATH`와 같은 폴더의 `ai-master.key`입니다. 운영 기본값은 `/srv/hwagae/shared/ai-master.key`이며 첫 키 저장 시 생성합니다. Linux 권한은 `0600`입니다. 환경 변수 `AI_SECRET_KEY_PATH`로 별도 영구 경로를 지정할 수 있습니다.
- **DB와 이 키 파일을 함께 안전하게 백업**해야 합니다. 키 파일을 잃으면 DB의 암호문을 복호화할 수 없습니다. 파일이 사라진 상태에서 복호화를 요청해도 새 키로 조용히 대체하지 않습니다. 배포 릴리스 폴더 안에 두지 마세요.
- DB 스냅샷에는 암호화된 이전 설정이 남을 수 있습니다. 연결 삭제는 공통 설정에서 제거하며 공급사에서 발급한 키를 폐기하지는 않습니다.
- 게이트웨이는 공개 HTTPS 주소만 허용합니다. 사설망·루프백·링크 로컬·메타데이터 주소와 혼합 DNS 응답은 차단합니다. 검증한 공인 IP에 연결을 고정하고 원래 호스트의 TLS 인증서·Host를 검증합니다. 환경 프록시를 사용하지 않으며 응답은 2MB로 제한합니다.
- 동시 수정은 revision으로 감지합니다. 충돌하면 설정을 새로고침하고 다시 저장합니다. AI 설정 변경은 기존 판매·재고·발주 기록을 변경하지 않습니다.

## 검증 범위

실제 API 키 없이 로컬 HTTPS 공급사와 응답 모형으로 키 보관·권한·모델 목록·세 API 형식·우선순위·자동 전환을 검증합니다. 실제 게이트웨이의 모델 지원·요금·가용성은 운영자가 키를 등록한 뒤 연결 테스트로 확인합니다.

Claude는 `/v1/models`와 `/v1/messages`, 별도 `system`과 `max_tokens`를 사용합니다. API 버전 `2026-10-21`, `Authorization: Bearer` 인증을 사용하며 `output_config.effort`로 지원되는 추론 강도를 전달합니다. 기본값은 강도를 생략하고 `none`·`minimal`은 자동 변환하지 않습니다. 답변의 텍스트만 표시하며 추론 블록·도구 요청·토큰 제한으로 잘린 응답은 성공으로 처리하지 않습니다. 실패하면 기존 순서대로 예비 연결을 사용합니다. [공식 Messages API](https://platform.claude.com/docs/en/api/messages/create), [모델 목록](https://platform.claude.com/docs/en/api/models/list), [추론 강도](https://platform.claude.com/docs/en/build-with-claude/effort).

모델 목록 조회 오류는 키·권한, 주소·연결 방식, 한도, 응답 지연, 공급사·통신 문제를 구분해 안내합니다. 공급사의 원문 오류나 키를 화면에 돌려주지 않습니다. JSON이 없는 중간 서버 502 응답도 AI 연결을 다시 확인하도록 안내합니다.

형식 참고: [OpenAI 모델 목록](https://developers.openai.com/api/reference/resources/models/methods/list), [추론 강도](https://developers.openai.com/api/docs/guides/reasoning), [Fernet 키 보관](https://cryptography.io/en/latest/fernet/).
